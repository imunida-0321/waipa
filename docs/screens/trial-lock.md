# お試しロック

| 項目   | 内容                                                                                             |
| ------ | ------------------------------------------------------------------------------------------------ |
| 画面ID | `trial-lock`                                                                                     |
| ルート | `/game/[id]`（`GameScreen` のゲーム本体の上に重ねて表示）                                        |
| 実装   | `src/components/game/trial-lock-overlay.tsx`、`src/lib/trial-store.ts`、`src/constants/trial.ts` |
| 種別   | オーバーレイ（プレミアム限定ゲームのみ）                                                         |

## 目的

お試しプレイで2ラウンド遊び終えた人に、続きはプレミアムで遊べることを伝え、ペイウォールへ誘導します。

## スクリーンショット

撮影できていません（補足を参照）。

## 表示項目

| No  | 項目           | 内容                                    |
| --- | -------------- | --------------------------------------- |
| 1   | 王冠           | 王冠のアイコン                          |
| 2   | 見出し         | 「お試しはここまで！」                  |
| 3   | 説明           | 「続きは WaiPa プレミアムで遊べます。」 |
| 4   | アップグレード | 「プレミアムにアップグレード」          |
| 5   | 戻るリンク     | 「ホームへ戻る」                        |

ゲーム本体の上に重なり、下のゲームは操作できなくなります。

## 表示条件

次のすべてを満たすときに表示します。

- プレミアム限定ゲーム（`meta.premium` が true）
- 未購読
- そのゲームのお試し中で、消費したラウンドが2（`TRIAL_ROUNDS`）以上

ラウンドの消費は、各ゲームのエントリのコンポーネントが `useTrialRoundConsumer(gameId, isRoundEnd)` で知らせます。何を1ラウンドとするかはゲームごとに違い、たとえばバーストチキンは結果が出るたび、ダウトダイスは誰かのライフが0になって結果が出るたびです。

2ラウンド目の結果が出た時点で重なるので、2ラウンド目の結果は、この下に表示されたままになります。

## 操作

| 操作                                   | 結果                                                                   |
| -------------------------------------- | ---------------------------------------------------------------------- |
| 「プレミアムにアップグレード」をタップ | [ペイウォール](paywall.md)へ進む。購入すると、このオーバーレイは消える |
| 「ホームへ戻る」をタップ               | ホームへ戻る                                                           |

ゲーム画面を離れると、お試しは終わります。「お試し済み」の記録は残るため、同じゲームのお試しはもうできません。

## 遷移

- 入口: お試しプレイ中のゲームで、2ラウンド目が終わったとき。
- 出口: [ペイウォール](paywall.md)、ホーム。

## 補足

- 撮影しようとして、バーストチキンでお試しプレイを始めましたが、リワード広告を見終わったあと画面がタップを受け付けなくなり、ここまで進めませんでした（[プレミアムロック](premium-lock.md) の補足）。
- 撮影のために、シミュレータでは「爆弾スワイプ」と「バーストチキン」がお試し済みになっています。
