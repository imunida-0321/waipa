| 項目   | 内容                                                                           |

| 画面ID | `splash`                                                                       |
| ルート | なし（全画面の上に重ねて表示）                                                 |
| 実装   | `src/components/splash-overlay.tsx`、`app.json` の `expo-splash-screen` の設定 |
| 種別   | オーバーレイ（起動時のみ）                                                     |

## 目的

アプリの起動中に、ロゴを出して待ってもらう画面です。

## 動き

1. 起動すると、OS のスプラッシュ（`expo-splash-screen`）がロゴを出す。`_layout.tsx` は読み込みの最初に、このスプラッシュを自動で消さないよう指示している
2. アプリの描画が始まると、同じロゴの `SplashOverlay` を重ねてから、OS のスプラッシュを消す
3. `SplashOverlay` が0.6秒かけてフェードアウトし、消えたあとは描画しない

OS のスプラッシュとアプリのオーバーレイを同じ見た目にして、切り替わりの継ぎ目を見せないようにしています。
