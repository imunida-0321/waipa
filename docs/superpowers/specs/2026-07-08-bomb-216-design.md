# BOMB!! 2/16 設計書（Issue #10）

日付: 2026-07-08
対象 Issue: #10 「#G2 BOMB!! 2/16」

## 概要

16 ボタン中に爆弾 2 個（1人負け＋全員負け）が隠れた運試しゲーム。スマホを回して 1 人 1 タップし、爆弾を引いた瞬間にゲーム終了。

## 確定ルール

- 盤面は 4×4 の 16 タイル。番号 1〜16 を表示
- ゲーム開始時（および「もう一回」時）に、互いに異なる 2 マスへランダム配置:
    - 「1人負け」爆弾 💣 … 引いた人だけアウト
    - 「全員負け」爆弾 💥 … 全員アウト
- プレイヤー登録とは連携しない。スマホ回しで即開始（`requiresPlayers` なし）
- タップ結果:
    - セーフ → タイル開封アニメ＋ランダムなリアクション文言（「セーフ！」等）、軽ハプティクス＋タップ音
    - 爆弾 → 画面シェイク＋強ハプティクス＋爆発音 → リザルトへ
- **爆弾 1 個目で即終了**。全員勝ちエンドは存在しない（セーフ 14 個を開け切ると残りは爆弾のみ）
- リザルト時は盤面を全公開し、引かなかった方の爆弾の位置も表示する
- 緊張感 UI: 盤面上部に「のこり ○マス」と爆弾確率「💣 2/○」を表示（開封のたび分母が減る）
- リザルト: 共通 `ResultOverlay`。「もう一回」= 盤面再シャッフル / 「ホームへ」= ホームに戻る

## 画面フロー

```
GameScreen（共通枠。初回は遊び方モーダル自動表示）
  └─ BombGame
       phase: 'play' ──爆弾タップ──▶ 'result'（ResultOverlay 表示、背後に全公開盤面）
              ▲──────「もう一回」（再シャッフル）──────┘
```

## 実装構成（`src/games/bomb-216/`）

| ファイル        | 責務                                                                                                                                            |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `board.ts`      | 純粋ロジック。`createBoard(rng?)` で爆弾 2 個を別マスに配置、`revealTile(board, index)` で開封と結果判定（`safe` / `solo` / `all`）。RNG 注入可 |
| `bomb-game.tsx` | phase 状態機械（play → result）。haptics / playSound / シェイクの発火、ResultOverlay 接続                                                       |
| `tile.tsx`      | Reanimated によるタイル。開封アニメ（スケール＋フェード）、爆発時の赤フラッシュ＋拡大                                                           |
| `theme.ts`      | ローカルカラー（赤系。registry の `#FF6B6B → #C0392B` 準拠）                                                                                    |

- `src/games/registry.ts`: `bomb-2-16` の `Component` を差し替え、`howToPlay` 文言を確定ルールに合わせて更新
- 効果音は既存規約どおり名前呼びのみ（`playSound('tap')` / `playSound('explosion')`）。音源未登録の間は無音スキップ
- ハプティクス: セーフ = `haptics.tap()`、爆発 = `haptics.heavy()`
- 画面シェイク: 盤面コンテナの translateX 振動（Reanimated withSequence）。追加依存なし

## エラーハンドリング / エッジケース

- 開封済みタイルの再タップは無視（disabled）
- result 中は盤面操作不可（Modal が覆う）
- アニメ中の連打で二重開封しないよう、開封処理は board 状態で冪等に
- 設定で効果音 / バイブ OFF の場合は既存の `sound.ts` / `haptics.ts` が吸収
