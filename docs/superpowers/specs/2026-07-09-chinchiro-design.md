# チンチロ（#G6 / Issue #52）設計スペック

日付: 2026-07-09
対象 Issue: #52（マイルストーン MVP v1.0、#14 指差しヒートアップの差し替え）
ブランチ: feature/52-chinchiro

## 概要

3個のサイコロを丼で振る伝統的なチンチロを1台回し系パーティーゲームとして実装する。全員（2〜12名）が順番に振り、役の強さでランキング。最弱が負け。賭け要素はなし。

## 確定済みの判断（ユーザー承認済み）

- **形式**: 全員ランキング（親子制なし）。5秒STOP と同じ「順番計測→ランキング発表」構造
- **振り直し**: 最大3投。役なしなら振り直し可、役が出たら即確定。3投して役なしなら「目なし」
- **ションベン**: 各投5%で発生。その投は無効（投数だけ消費、3投目なら目なし確定）
- **同率最下位**: サドンデス。当事者のみ1投勝負を決着まで繰り返す
- **立体表現**（2026-07-09 夜に本格3Dへ変更。参考動画準拠）: プレイ画面のサイコロは three.js（`three` + `@react-three/fiber` + `expo-gl`）による本物の3D描画。艶白キューブ（1・4の目=赤、他=青）、ダークネイビーの鏡面床（反転コピーによる映り込み）＋丼の縁リング、斜め上からのパースペクティブカメラ。**物理演算は使わず**、抽選済みの出目から最終姿勢を逆算しスクリプトでタンブル補間する（出目制御問題を回避、依存も増やさない）。ションベンは1個がリング外へ転がり出る。サドンデスのミニ表示はアイソメ SVG（IsoDie）を継続使用。Lottie の diceRoll スロットは廃止

## 役と序列

強い順。比較は `handScore`（整数）で行う:

| 役       | 出目              | handScore | 確定タイミング                 | 表示色           |
| -------- | ----------------- | --------- | ------------------------------ | ---------------- |
| ピンゾロ | 1,1,1             | 1000      | 即確定                         | 金（紙吹雪演出） |
| アラシ   | x,x,x（x=2..6）   | 900+x     | 即確定                         | 金               |
| シゴロ   | 4,5,6             | 800       | 即確定                         | ティール         |
| 目 n     | ペア＋n（n=1..6） | 100+n     | 即確定                         | 白               |
| 目なし   | 3投役なし         | 10        | 3投終了時                      | 黄               |
| ヒフミ   | 1,2,3             | 0         | 即確定（振り直し不可の最弱役） | 赤               |

- ションベンは最終役ではない（投の無効化のみ）。全投ションベン/役なしなら目なし
- ランキングは handScore 降順、同率はプレイヤー index 昇順で安定
- 敗者 = 最小 handScore の全員。2人以上ならサドンデスへ

## アーキテクチャ

5秒STOP と同じ「フェーズ状態機械（親）＋純関数ロジック」構成。

### ファイル構成

```
src/games/chinchiro/
  chinchiro-game.tsx   # 親: プレイヤーごとの計測ループ → リザルト
  dice.ts              # 純関数: 出目生成(rng注入) / 役判定 / handScore / 役名 / ランキング / 敗者
  iso-die.tsx          # アイソメトリックSVGサイコロ1個（value 1..6、サイズ・傾き指定可）
  dice-roll.tsx        # 1人分: スタンバイ → 転がり → 出目確定/振り直し → 記録ドン
  result.tsx           # ランキング発表 → （同率時）サドンデス → 敗者発表
  theme.ts             # ゲーム固有カラー（役色・丼色）
  __tests__/
```

### dice.ts（純関数、rng は引数注入でテスト可能に）

```ts
type Throw = { dice: [number, number, number]; shonben: boolean }
rollThrow(rng: () => number): Throw          // shonben 判定(5%) + 出目3個
evaluateDice(dice): Hand | null              // null = 役なし（この投では手なし）。非 null は即確定
resolveThrows(throws: Throw[]): Hand         // 投列から最終役（確定役 or 目なし）。shonben 投は無視
rankPlayers(hands: Hand[]): Ranked[]         // score降順・同率index昇順・isLoser
```

型: `Hand = { type: 'pinzoro'|'arashi'|'shigoro'|'me'|'hifumi'|'nome', value: number, score: number }`、表示名/色 tier はヘルパーで導出。

## 画面仕様

### dice-roll（1人分）

- **standby**: 「N人目 / M人」＋プレイヤーカラードット＋「◯◯さんの番」＋ GradientButton「タップで振る！」
- **rolling**: 丼（円形、金縁）内で転がり演出 約1.2秒
    - `LottieEffect` の新スロット `diceRoll`（`lottie-assets.ts` に `diceRoll: null` を追加。素材が来たら require に差し替え）
    - フォールバック: 疑似3Dタンブル（IsoDie 3個を perspective + rotateX/rotateY の wobble ＋ 出目高速切替で回転しているように見せる、reanimated）
    - `tap` 音＋haptics tap
- **確定/振り直し**: 転がり終了 → IsoDie 3個で出目を表示
    - 役あり → **record**: 役名を役色でドン！（DrumrollReveal revealed 流用）。ピンゾロは ConfettiBurst＋`reveal` 音＋haptics success。その他の確定は haptics heavy。「つぎの人へ」（最終プレイヤーは「結果発表へ」）
    - 役なし（残投あり）→ 出目と「役なし… のこりn投」表示＋「もう一度振る」ボタン
    - ションベン → サイコロ1個が丼の外へ滑り出るアニメ＋「ションベン！」赤表示＋`event` 音。残投あれば「のこりn投」、なければ目なし確定で record へ
- 投数は画面上部に「1投目/2投目/3投目」を常時表示

### iso-die（確定表示のサイコロ）

- react-native-svg で等角投影の立方体（上面＝出目、左右側面は陰影のみ）
- 上面の目は菱形グリッド上に楕円で配置（1・4・5 の目は赤、他は黒＝実物のサイコロ準拠。1のみ赤でも可、実装時に見た目優先で調整可）
- props: `value: 1..6`, `size`, `tilt`（±10度程度の傾き）

### result（ランキング発表＋サドンデス）

- 5秒STOP の result と同パターン: 1位から600ms間隔で順めくり（役名＋出目ミニ表示＋役色）、敗者（同率含む）は「？？？」のままドラムロール
- ドラムロール後:
    - 敗者1人 → 赤カードで「敗者！」ドン → アクションボタン表示
    - 同率複数 → 「同率最下位！サドンデス！」→ サドンデスモード: 当事者が順に1投ずつ振る（dice-roll の簡易版: 振り直しなし・ションベンあり=目なし扱い・役なし=目なし扱い）→ 全員振ったら比較、最小 score が敗者。また同率なら繰り返し → 敗者ドン → アクションボタン
- アクション: 「もう一回」（1人目から再スタート）／「ホームへ」（router.replace('/')）。5秒STOP 同様インライン表示

## 乱数とテスト方針

- `dice.ts` の全関数は `rng: () => number` を引数注入（`Math.random` 直接参照禁止）。コンポーネントからは既定で `Math.random` を渡す
- 単体テスト（dice.ts）: 役判定の全パターン（ピンゾロ/アラシ各目/シゴロ/目1..6/ヒフミ/役なし）、handScore の序列（隣接役の大小）、ションベン判定境界（rng=0.049/0.05）、resolveThrows（1投確定/3投目なし/ションベン混在）、rankPlayers（同率安定・複数敗者）
- コンポーネントテスト: dice-roll のフェーズ遷移（rng モックで出目固定）、振り直し回数の上限、result の順めくり→サドンデス→敗者発表（`await act(async)` / `await render` 規約、演出タイマーは fake timers。演出の連鎖タイマーは setInterval コールバック内で直接進める方式＝5秒STOP result.tsx の教訓に従う）
