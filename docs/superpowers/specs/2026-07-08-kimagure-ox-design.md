# きまぐれ◯× 設計（Issue #12 / #G4）

2026-07-08 承認済み

## 概要

普通の◯×ゲーム（3×3、2人、端末回し）に「きまぐれイベント」がランダム発生する変則ルールゲーム。
プレイヤー登録は不要（◯と×のみ、`requiresPlayers` なし）。

## ファイル構成

`src/games/kimagure-ox/` 配下。who-will-pay と同じ「純粋関数エンジン + フック/コンポーネント」構成。

| ファイル               | 責務                                                      |
| ---------------------- | --------------------------------------------------------- |
| `engine.ts`            | 盤面型・着手・勝敗判定の純粋関数                          |
| `events.ts`            | イベント4種の定義・抽選・適用の純粋関数（乱数は引数注入） |
| `kimagure-ox-game.tsx` | useReducer の状態機械（playing → cutin → finished）       |
| `board.tsx`            | 3×3盤面表示・タップ着手・封鎖マス表示                     |
| `event-cutin.tsx`      | イベントカットイン演出（reanimated）                      |
| `theme.ts`             | ゲームローカルの色トークン                                |
| `__tests__/`           | engine / events / ゲームコンポーネントのテスト            |

registry.ts は `kimagure-ox` の `Component` を差し替え、`howToPlay` を実ルールに合わせて更新する。

## データモデル

```ts
type Mark = 'o' | 'x'
type Cell = Mark | null

type GameState = {
	board: Cell[] // 長さ9
	turn: Mark // 現在の手番
	blocked: number | null // 封鎖マス index（同時に1つまで、永続）
	extraMoves: number // ダブル手番の残り回数
	moveCount: number // 着手数（イベント抽選条件に使用）
	lastEvent: EventId | null
	phase: 'playing' | 'cutin' | 'finished'
	winner: Mark | 'draw' | null
}
```

## ルール

1. 先手はゲーム開始時にランダム決定（コイントス演出で表示）。
2. 着手: 手番プレイヤーが空きマス（封鎖マス除く）をタップして配置。
3. 勝敗判定: 縦横斜めの3並びで勝ち。9マス（封鎖含む）すべて埋まって勝者なしなら引き分け。
4. イベント抽選: 各着手後、勝敗未決のときに **30%** で発生。
    - 1手目・2手目の着手後は発生しない（3手目の着手後から抽選対象）。
    - 直前に発生したイベントと同じものは選ばれない。
    - 適用不能なイベントは候補から除外（下記）。候補が空なら発生しない。
5. イベント後も勝敗判定を行う。イベントの結果3つ並んだら即勝利。両者同時に並んだら引き分け。

## きまぐれイベント（4種）

| ID        | 名称           | 効果                                                     | 適用不能条件（候補から除外）     |
| --------- | -------------- | -------------------------------------------------------- | -------------------------------- |
| `shuffle` | マスシャッフル | 盤上の駒の位置をランダムに再配置（封鎖マスには置かない） | 盤上の駒が1個以下                |
| `block`   | 1マス封鎖      | ランダムな空きマス1つを永続封鎖                          | 既に封鎖がある / 空きマスが1以下 |
| `vanish`  | 駒消滅         | 盤上の駒1個がランダムに消える（どちらの駒かもランダム）  | 盤上に駒がない                   |
| `double`  | ダブル手番     | 次のプレイヤーが2回連続で置ける                          | なし                             |

補足: `vanish` は Issue 文面では「相手の駒1つ消滅」だが、「どちらが消えるかもきまぐれ」の完全ランダム仕様で承認済み（公平性とカットイン文言の簡潔さを優先）。

## 演出

- **カットイン**: イベント発生時に全画面オーバーレイでイベント名＋絵文字をバーンと表示（reanimated の scale + shake）。表示中は盤面操作不可。`playSound('event')` と `haptics.heavy()` を呼ぶ。イベント効果の盤面反映はカットイン終了後に見せる（カットイン→盤面更新の順）。
- **リザルト**: 共通 `ResultOverlay`（もう一回 / ホームへ）。中身は勝者マークの大表示（「◯の勝ち！」「引き分け」）。`haptics.success()`。
- **効果音**: `playSound` を呼ぶが、音源ファイルはプロジェクト全体で未登録のため当面は無音スキップ（sound.ts の仕様）。音源追加は全ゲーム共通の別課題とする。

## テスト方針

- `engine.ts`: 勝敗判定（全ライン・引き分け）、着手バリデーション（封鎖・使用済みマス拒否）。
- `events.ts`: 各イベントの適用結果、適用不能条件の除外、抽選（確率・序盤抑制・連続抑制）を乱数注入で決定的に検証。
- `kimagure-ox-game.tsx`: 状態遷移（着手→カットイン→リザルト）、リトライで初期化。既存 who-will-pay-game.test.tsx のパターンに従う。
