# ホーム画面レイアウト刷新（千鳥グリッド） 設計書（Issue #44）

日付: 2026-07-20
対象 Issue: #44 「ホーム画面レイアウト刷新: 候補案まとめ」
ブランチ: feature/44-home-staggered-grid（develop ベース）

## 目的

現行ホーム（ヒーローバナー → 2列グリッド → カード下キャッチ）は参考アプリと構成がほぼ同じで独自性がない。候補4案から **案3: 千鳥（ずらし）グリッド** を採用し、「開いた瞬間にすぐ選んで始める」ホームに刷新する。

## 決定事項（2026-07-20 ブレスト）

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| レイアウト | 案3: 千鳥グリッド（右列を半タイル下げた2列グリッド） | 収録15ゲームでの一覧性が最良クラス、実装コスト最小級、「よくある2列グリッド」に見えず差別化目的を最も満たす |
| タイル比率 | **1.3:1 のまま**（モックの正方形は採用しない） | 既存のタイトル文字入り card.jpg 8枚（1040x800）をそのまま使え、画像作業ゼロ。ずらし効果は比率に依存しない。将来正方形化する場合は画像差し替え＋style 変更のみで移行可 |
| ヒーローバナー | **残す**（現行の固定ブランドバナー1枚を維持） | 2026-07-20 レビューで Issue 起票時の「撤去」方針を上書き。差別化は千鳥グリッド＋タイトル内蔵＋バッジで担う |
| 「ゲーム一覧」見出し | 残す | バナーを残すため、バナーとグリッドの区切りとして現行構成を維持 |
| カード下キャッチ（tagline） | ホームでは廃止（イントロ画面では継続使用） | Issue #44 の決定済み方向性（タイトルはサムネ内へ） |
| バッジ | **人数バッジのみ**をサムネ左上にオーバーレイ。所要時間バッジは表示しない | 2026-07-20 レビューで所要時間表示は不要と判断（Issue 起票時の方向性を上書き）。`GameMeta` への `duration` 追加も不要になる |

案1（バナー型）は1画面5〜6本でスクロール過多、案4（大正方形リスト）も1列で同傾向＋正方形画像の再書き出しが必要なため見送り。案2は差別化効果が4案中最弱。

## 非目標（YAGNI / 別 issue）

- card.jpg の正方形再書き出し・未作成7ゲーム分のキービジュアル制作（画像が揃い次第 meta に足すだけで反映される構造は維持）
- ホームの検索・カテゴリ・お気に入り・並び替え
- ヒーローバナーの動的化（お知らせ・新作訴求のカルーセル化は必要になったら別 issue）
- プレミアムロック・お試しプレイ・広告まわりの挙動変更（現行維持で載せ替えのみ）

## 現状

- ホームは `src/app/index.tsx` → `HomeHeader` / `HeroBanner` / `SectionHeader("ゲーム一覧")` / `GameGrid`（flexWrap 2列） / `HomeBannerAd`（下部固定）
- `GameCard`（`src/components/home/game-card.tsx`）: 1.3:1 サムネ（card.jpg があれば画像・なければグラデ＋絵文字＋中央タイトル）＋カード下 tagline。プレミアム未解放は黒マスク＋👑バッジ、タップで `PremiumLockModal`
- レジストリ登録は15ゲーム（プレミアム7）。card.jpg あり8 / なし（グラデフォールバック）7
- `GameMeta`（`src/games/types.ts`）に `duration` は未定義。人数は `minPlayers` / `maxPlayers` あり

## 設計

### 1. 人数表示の整形（レイアウト非依存の下準備）

- `GameMeta` の変更は**なし**（所要時間バッジ不要のため `duration` 追加も不要）
- 人数バッジの整形は純関数 `formatPlayerCount(min, max)` を `src/lib/` に新設: `min === max` なら `'2人'`、それ以外は `'2〜8人'`。既存 `minPlayers` / `maxPlayers` から生成

### 2. 人数バッジUI: `PlayerCountBadge`（`src/components/home/player-count-badge.tsx`）

- props: `{ game: GameMeta }`。人数ピル1つを描画
- 見た目（モック準拠）: 背景 `rgba(0,0,0,0.28)`、pill 角丸、白 caption テキスト
- サムネ左上（`position: absolute`）に配置。画像・グラデフォールバック両方に重ねる

### 3. GameCard 刷新（`game-card.tsx`）

- 1.3:1 サムネは維持。card.jpg あり: 画像のみ（タイトルは焼き込み済みなので重ねない）
- グラデフォールバック（7ゲーム）をモック準拠に変更: グラデ背景＋大きめ絵文字（右上寄り・opacity 0.55 前後）＋**タイル内左下にタイトル**（太字、2行まで）
- `PlayerCountBadge` を左上にオーバーレイ
- カード下の tagline 表示を削除
- プレミアムロック（黒マスク＋👑バッジ）は最前面のまま変更なし（バッジはマスク下で減光される）

### 4. 千鳥グリッド（`game-grid.tsx` 改修）

- flexWrap をやめ、2カラム構成に変更: `games` を偶数 index → 左列、奇数 index → 右列に分割し、`View` 2本を横並び
- 右列に**半タイル分の上オフセット**。RN のパーセンテージ padding/margin は親幅基準なので、タイル高 = 48% ÷ 1.3 ≒ 36.9% → オフセットは `paddingTop: '18.5%'` を右列に適用（実装時に実機/スクショで微調整可）
- 15本なので左8・右7。タップ遷移・ハプティクス・`PremiumLockModal` のロジックは現行を維持

### 5. 画面構成（`index.tsx`）

- **変更なし**。`HomeHeader` → `HeroBanner` → `SectionHeader("ゲーム一覧")` → 千鳥 `GameGrid` → `HomeBannerAd` の現行構成を維持し、変更は `GameGrid` / `GameCard` の内部に閉じる

## テスト計画（TDD: RED → GREEN → REFACTOR）

1. `formatPlayerCount`: `(2,2) → '2人'` / `(2,8) → '2〜8人'`
2. `PlayerCountBadge`: 人数ピルのテキスト表示（`2人` / `2〜8人`）
3. `GameCard`: 人数バッジ表示 / tagline 非表示 / フォールバック時のタイル内タイトル / ロックマスク維持（既存テスト更新）
4. `GameGrid`: 左右列への分割（左8・右7）と右列オフセット style / ロックモーダル挙動維持（既存テスト更新）

`index.tsx` は無変更のため既存 index テストはそのまま。既存テストの tagline 依存の更新は仕様変更に伴うものであり、「実装に合わせたテスト改変」には当たらない。
