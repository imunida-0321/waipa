# 爆弾スワイプ度胸試し（#63）設計書

2026-07-13 確定。issue #63 のルールをベースに、ブレスト（本人確認済み）で以下を決定した。

## 決定事項

| 論点               | 決定                                                                                         |
| ------------------ | -------------------------------------------------------------------------------------------- |
| 地雷の位置         | **各プレイヤーごとにランダム**（前の人の爆発から情報が漏れない。全員同条件の純粋な度胸試し） |
| 同率最低スコア     | **同率は全員負け**（チンチロ等の複数敗者表現と同じ）                                         |
| スワイプ中のスコア | **数字をリアルタイム表示**（0〜100。緊張感と周囲の盛り上がり優先）                           |
| 地雷ちょうど       | **スコア ≥ 地雷位置で爆発**（踏んだらアウト）                                                |

## ルール仕様

- 2〜12人、プレイヤー登録必須（`requiresPlayers: true`。ランキングに名前を表示するため）
- 1台回し。各プレイヤー1回ずつスワイプして1周で決着
- 画面下から上へゲージをスワイプし、指を離した位置が整数スコア 0〜100
- 地雷はプレイヤーごとに `MINE_MIN`〜`MINE_MAX`（初期値 60〜95）の一様乱数（整数・非表示）
- スコア ≥ 地雷位置 なら爆発
- 敗者判定:
    1. 爆発者が1人以上 → 爆発者全員が負け
    2. 爆発者ゼロ → 最低スコアの全員が負け（同率含む）
    3. 全員爆発 → 全員負け（全員飲み演出）
- スワイプせず離した場合もスコア0で有効（それが最低なら通常どおり負け）
- 地雷範囲はプレイテストで調整する前提で theme.ts に定数化

## 画面フロー

```
イントロ（遊び方）
→ 手番表示「〇〇さんの番」
→ スワイプ（リアルタイムスコア＋緊張演出）
→ セーフ確定（スコアドン）or 爆発演出
→ 端末受け渡し画面
→（全員終了まで繰り返し）
→ リザルト: ドラムロール → スコアランキング＋地雷位置の答え合わせ → 敗者ドン
```

## 演出

- 緊張カーブ: スコアに比例して背景の赤み・ハートビート音のテンポ・バイブ間隔を連続的に強める
- 爆発: 既存 explosion Lottie ＋ explosion.m4a ＋ haptics.heavy ＋ 画面フラッシュを流用
- リザルト: drumroll.m4a 流用
