# 飲みゲー衰弱（罰ゲーム神経衰弱・プレミアム）設計

2026-07-10 確定。2026-07-12 改訂（カード表面の罰テキスト秘匿化・成立演出の追加・罰プリセット全文の確定・プレミアム基盤の既存化を反映）。

## 決定事項

- **#16「リアクション神経衰弱」とは別の新規ゲーム**として追加する（#16 は原案のまま残す）
- **プレミアム限定ゲーム（全体ロック）**: 既存のプレミアム基盤（#61 バーストチキン / #58 ダウトダイスで実装済みの `GameMeta.premium` フラグ＋👑 バッジ＋`premium-lock-modal`）に `premium: true` で乗る。RevenueCat(#7) 実装までは案内モーダルのスタブ＋開発ビルドでは解放
- **お酒表現はそのまま使う**（飲む量の単位は「◯杯」表現で統一）。年齢レーティング 17+/Mature 前提
- **カードは普通のトランプ**: 表面は中央に大きくランク＋スートのみ。**罰テキストはペア成立まで秘匿**（盤面カード上には一切表示しない）
- **ペア成立演出**: マッチした2枚のランク＋スートがフェードし、罰テキストが**うっすら浮かび上がる** → punish オーバーレイで全文発表 → 場から除外
- **揃えた人が実行者を口頭指名**（アプリは煽り表示のみ、指名ロジックは持たない）
- **手番は1人1ターン固定**: 揃っても揃わなくても次の人へ
- **ジョーカー2枚**（ペアなし単独カード）: めくった瞬間に特大罰が発動、めくった本人が実行。場から除外され手番は即終了
- **盤面サイズ選択式**: 小 4×4（7ペア＋J2）/ 中 4×5（9ペア＋J2）/ 大 5×6（14ペア＋J2）
- **全ペア消化で終了 → 獲得ペア数ランキング**をリザルト表示（最下位ハイライト）
- **お題はアプリ内プリセット**: 通常罰 40個＋特大罰 10個（全文は本書末尾に確定収録）。カスタムお題編集は別課金機能として別 Issue（本ゲームのスコープ外）
- 参加人数 2〜12 人、`requiresPlayers: true`（ランキングに参加メンバーが必要）
- **実装アプローチ**: 純粋エンジン＋reducer 方式（きまぐれ◯× / 王様のいない王様ゲーム 準拠）

## 画面フロー

```
size（盤面サイズ選択）→ play（盤面・手番回し）→ punish（罰発表オーバーレイ）→ play
                                    └→ 全ペア消化 → result（ランキング）
```

- **size**: 小/中/大の3択カード（ペア数・目安時間つき）＋「スタート」。参加メンバーは既存プレイヤー登録ゲートで事前登録済み
- **play**: グリッド盤面＋ヘッダーに「◯◯さんの番」（プレイヤーカラー）。1人2枚めくる
    - めくり: カードフリップアニメ。表面＝中央に大きくランク＋スートのみ（罰テキストなし）
    - 不成立: 2枚を約1.5秒見せて自動で裏返し、次の人の名前を表示
    - 成立: マッチした2枚のランク＋スートがフェードアウトし、罰テキストがうっすら浮かび上がる短い演出（約1秒）→ punish オーバーレイへ
- **punish**（ペア成立時）: カードがズームし罰テキストをドン！と大きく発表（効果音＋バイブ）→「◯◯さん、誰にやらせる？」の煽り表示 →「実行した！」タップで play に戻り次の人へ。獲得ペアは成立させた人にカウント。マッチした2枚は場から除外
- **punish**（ジョーカー時）: 禍々しい特別演出で特大罰を発表 →「◯◯さんが実行！」→ ジョーカーは場から除外、2枚目はめくれず手番終了
- **result**: 獲得ペア数ランキング（同数は同順位）。最下位をハイライト＋「もう一回」

## カードデザイン

- 表面: カード地は明るめサーフェス、中央に大きくランク＋スート（♥♦は赤系ネオン、♠♣は白）。**罰テキストは載せない**
- ペアは同一カード2枚（同ランク・同スート）。マッチ判定は `pairId` で行う
- 罰はデッキ生成時にペアへ割り当て済みだが、UI 上はペア成立（成立演出〜punish オーバーレイ）まで公開しない
- 成立演出: ランク＋スートが opacity フェードで消え、罰テキストが低 opacity で浮かび上がるクロスフェード
- ジョーカー: 「JOKER」表記＋紫×赤の禍々しい特別デザイン（表面に特大罰テキストは載せない。オーバーレイで公開）
- 裏面: WaiPa ネオン調（ダークネイビー地×ピンク紫グラデのロゴ柄）
- ランク＋スートは標準52枚デッキからペア数ぶんランダム抽出（重複なし）

## 状態設計

```ts
type BoardSize = 'small' | 'medium' | 'large' // 4×4 / 4×5 / 5×6
type Card = {
	id: string // 'p3-a' | 'p3-b' | 'joker-1'
	pairId: string | null // ジョーカーは null
	rank: string // 'A'..'K' | 'JOKER'
	suit: '♠' | '♥' | '♦' | '♣' | null
	punishment: string // ペア成立（またはジョーカー発動）まで UI には出さない
	state: 'hidden' | 'revealed' | 'removed'
}
type Phase = 'size' | 'play' | 'punish' | 'result'
type State = {
	phase: Phase
	size: BoardSize
	cards: Card[]
	turnIndex: number // 参加プレイヤー index（周回）
	flippedIds: string[] // 今ターンめくったカード（0..2枚）
	scores: number[] // player index → 獲得ペア数
	punish: { kind: 'pair' | 'joker'; text: string; playerIndex: number } | null
}
```

- 罰割当はデッキ生成時（`engine.createDeck(size)`）: normal プールからペア数ぶん、special プールから2つを重複なしランダム抽出。割当は決定的にテスト可能だが、UI では成立まで秘匿
- 罰プールは `punishments.ts` のプリセット。`{ id, text, type: 'normal' | 'special' }` 形式で、将来 topics-store の pack（Supabase 配信・課金パック）に載せ替え可能な ID 設計にする（`n01`〜`n40` / `s01`〜`s10`）

## エッジケース

| ケース                             | 対応                                                       |
| ---------------------------------- | ---------------------------------------------------------- |
| 同ターンに同じカードを再タップ     | 無効（`flippedIds` 済み・`removed` はタップ不可）          |
| ジョーカーが1枚目                  | 即 punish。2枚目はめくれず手番終了。1枚目は裏に戻さず除外  |
| ジョーカーが2枚目                  | 即 punish。1枚目は裏に戻す                                 |
| punish 表示中の盤面タップ          | オーバーレイでブロック                                     |
| 罰テキストが長い                   | 成立演出のうっすら表示は2行で省略可、punish オーバーレイで全文表示 |
| 大盤面でプール枯渇                 | しない設計（normal 40 ≥ 14、special 10 ≥ 2）を維持する     |
| アニメ中の連打                     | フリップ/クロスフェード完了まで次のタップを無視            |
| プレミアム未購入                   | ゲーム画面に入らずアップグレード案内モーダル（既存基盤、#7 で課金結線） |
| n40 ラッキーカード成立             | punish オーバーレイの煽りを「ラッキー！全員から拍手！」に差し替え（「誰にやらせる？」は出さない） |

## テスト方針

- engine: デッキ生成（サイズごとの枚数・ペア数・ジョーカー2枚・罰の重複なし）、マッチ判定、ランク/スートの重複なし
- reducer: play→punish→play 遷移、ジョーカー1枚目/2枚目の分岐、手番周回、scores 加算、全消化→result
- 秘匿性: 盤面カードコンポーネントが罰テキストを描画しないこと（punish フェーズ前）をテストで担保（ダウトダイス #58 の秘匿テストが参照例）
- コンポーネント: フリップ→罰発表のスモークテスト。React 19 の await act 規約に従う（kimagure-ox が参照実装）

## 収益・リリース面

- プレミアム全体ロック。無料ユーザーへの露出はホームカード（👑 バッジ）のみで、プレミアム訴求材料を兼ねる
- 飲酒表現を含むため、ストア申請時に年齢レーティング（App Store 17+ / Google Play 高レーティング）の質問票へ反映が必要
- 「一気コール」系の罰は急性アルコール中毒リスクとストア審査面から不採用。飲む量は「◯杯〜グラス半分」まで、最大でも「グラスの残りを飲み干す（無理は禁物！）」に抑える
- カスタムお題編集（ユーザー独自の罰ゲーム追加）は別課金機能として別 Issue で管理
