# カスタムお題編集（#68）設計 — 2026-07-19

飲酒衰弱の罰ゲームお題をユーザーが自分で追加・編集できる機能。名前付き「セット」単位で保存・切り替えできる（例: 会社飲み用 / サークル用）。

## 決定事項（ユーザー承認済み 2026-07-19）

- **セット対応（A案）**: データ構造は最初からセット対応。UI は最小構成（デフォルトセット1つ＋セット追加）から始める
- **運営配信プリセットパック（B案）は別 Issue** に切り出し（リリース後のコンテンツ施策）
- **特大罰（ジョーカー用）のカスタムも可**（タブ分離・上限少なめ）
- **課金ゲートは追加しない**: 飲酒衰弱自体がプレミアム全体ロック（2026-07-11 方針）のため、ゲームに入れた時点で解放済み。`isPremiumUnlocked()` の追加結線は不要
- **ローカル完結**（AsyncStorage のみ・共有機能なし）→ UGC 審査リスク低。編集シートに「この端末にのみ保存されます」を明記
- 画面イメージはチャットで提示したモック準拠（入口=盤面サイズ選択画面 / 一覧シート / 追加・編集フォーム）

## データモデル

```ts
export type CustomPunishment = { id: string; text: string; type: 'normal' | 'special' }
export type CustomSet = { id: string; name: string; items: CustomPunishment[] }
export type CustomPunishmentsState = {
	enabled: boolean // 「デッキに混ぜる」トグル
	activeSetId: string
	sets: CustomSet[]
	nextId: number // アイテム ID 採番用（Date.now 不使用でテスト容易に）
}
```

- ストレージキー: `waipa.inshu-suijaku.custom-punishments`
- アイテム ID: `c${nextId}`（プリセットの `n01`/`s01` と衝突しない接頭辞）
- デフォルトセット: `{ id: 'set1', name: 'マイセット', items: [] }`、セット ID は `set${nextId}`

## 上限・バリデーション

- 通常罰: セットごと **20件** / 特大罰: セットごと **5件**
- お題テキスト: **40文字**（罰カード表示領域に収まる長さ）。空白のみは保存不可
- セット数: **5個**。セット名: 12文字、空なら「セット{n}」フォールバック

## デッキへの混ぜ方（engine）

- `createDeck(size, rng, custom?)` に省略可能な第3引数 `{ normals: Punishment[]; specials: Punishment[] }` を追加
- **カスタム優先**: `shuffle(custom.normals) ++ shuffle(NORMAL_PUNISHMENTS)` の先頭から `pairs` 件を採用（「せっかく書いたのに出ない」を避ける）。特大罰も同様に先頭から `JOKER_COUNT` 件
- `enabled=false` またはアクティブセットが空なら従来どおりプリセットのみ
- プレイテストで「全部カスタムになりすぎる」となれば混合比を調整（フォローアップ）

## UI

1. **入口**: `SizeSelect` に「カスタムお題」行（👑アイコン＋有効件数表示）を追加 → 一覧シートを開く
2. **一覧シート**（Modal）: ×ヘッダー / セット選択チップ＋セット追加 / 「デッキに混ぜる」トグル / 通常罰・特大罰タブ（件数 n/20・n/5 表示）/ お題行（左端アクセントバー・編集・削除）/ 破線「⊕ 追加」/ 白い「完了」ボタン（プレイヤー設定画面と同じ文法）
3. **追加・編集フォーム**: 種類セグメント（通常罰/特大罰）/ テキスト入力＋文字数カウンタ（n/40）/「保存する」/ 注記「この端末にのみ保存されます」
