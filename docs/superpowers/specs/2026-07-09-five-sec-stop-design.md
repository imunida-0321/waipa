# 5秒STOP（#G3 / Issue #11）設計スペック

日付: 2026-07-09
対象 Issue: #11（マイルストーン MVP v1.0）
ブランチ: feature/11-five-sec-stop

## 概要

5.00 秒ぴったりを狙ってタイマーを止めるゲーム。プレイヤー全員が順番に1台のスマホで計測し、5.00 秒から一番遠かった人が負け。±0.05 秒以内は「ぴったり賞」として特別演出を出す。

## 確定済みの判断（ユーザー承認済み）

- **記録の公開**: 各プレイヤーが止めた直後、その場で記録をドン！と表示する（最後まで隠さない）
- **同率最下位**: 全員負けとして発表する（サドンデスなし）
- **数字の隠蔽**: 2.5 秒から 3.0 秒にかけて数字が徐々にフェードアウトし、以降は「？？？」表示
- **リザルト**: ランキング発表形式（案A）。1位から順にカードをめくり、最下位だけドラムロールで引っ張って発表
- **UX 採用項目**: ①全画面ストップ ②数字フェードアウト ③ズレ量による色分け ⑥段階ハプティクス ＋ ⑤の数直線は不採用（ランキングに変更）

## アーキテクチャ

who-will-pay と同じ「フェーズ状態機械＋純関数ロジック」構成。reducer エンジン（kimagure-ox 型）はターン進行が単純なため採用しない。

### ファイル構成

```
src/games/five-sec-stop/
  five-sec-stop-game.tsx   # フェーズ状態機械（親）。players-store から参加者取得
  stopwatch-play.tsx       # 1人分の画面: スタンバイ → 計測 → 記録ドン！
  use-stopwatch.ts         # 計測フック（開始時刻からの Date.now() 差分＋約60fpsの表示更新）
  judge.ts                 # 純関数: 敗者判定 / ぴったり賞判定 / 色分け / フォーマット
  result.tsx               # ランキング発表（1位から順にめくり→最下位ドラムロール）
  theme.ts                 # ゲーム固有カラー（ティール基調＋偏差色）
  __tests__/               # judge の単体テスト＋フェーズ遷移の統合テスト
```

### フェーズ遷移（five-sec-stop-game.tsx）

```
standby(次のプレイヤー表示) → measuring(計測中) → record(記録ドン！/ぴったり賞)
   ↑                                                      |
   └────────── 次のプレイヤーがいる間はループ ──────────────┘
                             ↓ 全員終了
                        result(ランキング発表)
```

- `usePlayers()` + `getDisplayNames()` で参加者を取得（registry を `requiresPlayers: true` に変更、2〜12名）
- 記録は `records: number[]`（ms 整数）として親が保持

## 計測仕様（use-stopwatch.ts）

- **記録の確定**: ストップ時に `Date.now() - startedAt` で算出。表示更新の setInterval には依存しない（描画フレーム落ちが記録精度に影響しない）
- **表示更新**: 約 16ms 間隔の setInterval で経過 ms を state 更新（フェードアウト後は「？？？」を出すだけなので更新継続は演出用）
- **誤爆ガード**: スタート後 300ms 未満のタップはストップ無効
- **単位**: 内部はすべて ms 整数。浮動小数の比較誤差を避ける

## 判定仕様（judge.ts / 純関数）

- `deviation(ms)` = `|ms - 5000|`
- **敗者**: deviation が最大のプレイヤー全員（同率は複数敗者）
- **ぴったり賞**: deviation ≤ 50（50ms ちょうどを含む）
- **色分け**（記録表示・ランキング共通）:
    - deviation ≤ 50 → 金（ぴったり賞）
    - deviation ≤ 200 → ティール（いい線）
    - deviation ≤ 500 → 黄（おしい）
    - それ以上 → 赤
- `formatSeconds(ms)` = 小数2桁の秒表示（例 `5.32`）。符号付き偏差表示 `formatDeviation(ms)`（例 `+0.32` / `−0.02`）
- ランキング順: deviation 昇順。同率は計測順で安定ソート

## 画面仕様

### standby（スタンバイ）

- 「N人目 / 全M人」と「◯◯さんの番」を表示（プレイヤーカラーの縦バーorドット付き）
- 「タップでスタート」ボタン。本人がタップして計測開始

### measuring（計測中）

- 中央に大きなタイマー数字（`0.00`〜）。ティール基調
- 2.5 秒 → 3.0 秒で数字の opacity を 1→0 にフェード。3.0 秒以降は「？？？」（脈打ちアニメ）
- **画面全体がストップ判定**（Pressable を全面に）。ガイド文言「画面のどこでもタップでストップ！」
- スタート時: haptics `tap`＋`tap` 音 / ストップ時: haptics `heavy`＋`tap` 音

### record（記録ドン！）

- DrumrollReveal を `phase="revealed"` で直接マウントし、待ちなしの withSpring ポップインで「5.32」を偏差色でドン！と表示。偏差ラベル（`+0.32 ズレ`）併記
- **ぴったり賞**（deviation ≤ 50）: 金色表示＋紙吹雪調パーティクル＋`reveal` 音＋成功ハプティクス。「＼ ぴったり賞 ／」見出し
- 「つぎの人へ」ボタンで standby へ（最終プレイヤーなら result へ）

### result（ランキング発表）

- 1位から順にカードが約 0.6 秒間隔でめくれて表示（プレイヤーカラードット＋名前＋記録＋偏差、1位カードは金枠、ぴったり賞バッジ）
- 最下位カードだけ「？？？」のまま残し、`drumroll` 音＋脈打ち → `reveal` 音で赤くドン！と発表（同率複数なら複数枚同時）
- 発表後にアクションボタン（もう一回 / ホームへ）をランキングの下にインライン表示（ResultOverlay のモーダルは一覧を隠すため使わない。who-will-pay の Result と同方式）。「もう一回」は standby（1人目）へリセット
